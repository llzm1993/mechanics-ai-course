# 《力学》AI 智慧课程

> 基于人工智能的大学物理《力学》互动教学平台 —— 用 3D 互动闪卡与物理过程可视化，让抽象的力学概念变得可感、可玩、可懂。

## 项目简介

本项目是一个**纯静态前端**的开放教学站点，依托 AI 重构传统力学课堂的学习体验：

- 🧠 **AI 知识梳理**：自动提炼核心概念、易错点与知识图谱
- 🎴 **3D 互动闪卡**：公式、概念与三维示意结合，翻转记忆
- 🌀 **物理过程可视化**：实时三维动画演示陀螺进动、角动量变化等
- 📈 **自适应学习**：根据反馈动态调整难度与重点

## 课程结构（三阶段 · 12 章）

课程按「**课前预习 → 课中互动演示 → 课后 3D 互动闪卡**」三阶段组织，每阶段覆盖相同的 12 章力学大纲：

| 章 | 主题 | 章 | 主题 |
| --- | --- | --- | --- |
| 01 | 质点运动学 | 07 | 刚体平面运动 |
| 02 | 牛顿运动定律 | 08 | 机械振动 |
| 03 | 动量守恒 | 09 | 机械波 |
| 04 | 动能定理与功能原理 | 10 | 流体力学 |
| 05 | 角动量与力矩 | 11 | 万有引力与天体运动 |
| 06 | 刚体定轴转动 | 12 | 狭义相对论基础 |

- **课前预习**：每章配套预习导引与前置知识（建设中）
- **课中互动演示**：实时三维交互演示（第 6 章已上线）
- **课后 3D 互动闪卡**：每章 3D 闪卡播放器（第 1 章已上线）

## 学习路径

力学中的瞬时速度、加速度、功与能，本质上都是微积分思想的物理表达。建议学习顺序：

1. **先修基础（必备）**：微积分晋级闯关游戏 —— 掌握极限、导数、积分与变化率
   👉 https://llzm1993.github.io/calculus-rank-quest/
2. **课前预习**：进入各章预习导引
3. **课中互动演示**：课堂实时演示，把数学语言映射到物理过程
4. **课后 3D 互动闪卡**：翻转记忆、自测巩固

> 微积分游戏为独立托管的外部项目，主页以新标签页打开，不影响本课程仓库。

## 本地预览

项目无任何构建步骤，直接用浏览器打开 `index.html` 即可：

```bash
# 方式一：直接双击 index.html
# 方式二：启动一个本地静态服务器（推荐，避免个别浏览器对本地文件的限制）
cd 力学
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 在 GitHub 上 **New repository**，仓库名建议为 `mechanics-ai-course`（或任意名称）。
2. 将本仓库推送到 GitHub：
   ```bash
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git branch -M main
   git push -u origin main
   ```
3. 进入仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`，
   Branch 选择 `main`、目录选 `/ (root)`，保存。
4. 稍等片刻，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可看到课程主页。

> 主页 `index.html` 位于仓库根目录，GitHub Pages 会自动将其作为站点首页。
