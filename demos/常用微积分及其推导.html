第一部分：微积分基础概念与核心定义

核心概念

1.1 导数与微分的严格定义

$$f'(x_0) = \lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x) - f(x_0)}{\Delta x}$$ $$dy = f'(x)\,dx \quad \iff \quad \frac{dy}{dx} = f'(x)$$

1. 导数的本质与极限描述： 导数刻画了函数因变量相对于自变量变化的瞬时变化率。设函数 $y = f(x)$ 在点 $x_0$ 的某邻域内有定义，若差商极限存在，则称 $f(x)$ 在 $x_0$ 处可导。

2. 微分的概念： 若函数增量可表示为 $\Delta y = A \Delta x + o(\Delta x)$（其中 $A$ 是与 $\Delta x$ 无关的常数，$o(\Delta x)$ 为高阶无穷小），则称函数在该点可微，并称线性主部 $A \Delta x$ 为函数的微分，记作 $dy = A \Delta x = f'(x)dx$。

3. 几何意义： 导数 $f'(x_0)$ 是曲线 $y=f(x)$ 在点 $(x_0, f(x_0))$ 处切线的斜率 $k = \tan \alpha$。切线方程为：$y - f(x_0) = f'(x_0)(x - x_0)$。

核心概念

1.2 原函数与不定积分的定义

$$\int f(x)\,dx = F(x) + C \quad \Longleftrightarrow \quad \frac{d}{dx}[F(x) + C] = f(x)$$

1. 原函数的存在性： 若在区间 $I$ 上 $F'(x) = f(x)$，则称 $F(x)$ 为 $f(x)$ 在该区间上的一个原函数。连续函数必有原函数。

2. 任意常数 $C$ 的本质： 若 $F_1(x)$ 与 $F_2(x)$ 均为 $f(x)$ 的原函数，则由拉格朗日中值定理推论可得：$\frac{d}{dx}[F_1(x) - F_2(x)] = 0 \implies F_1(x) - F_2(x) = C$（常数）。

3. 几何意义： 不定积分代表一簇沿 $y$ 轴垂直平移的积分曲线族，曲线上任意横坐标 $x$ 相同处的切线斜率均恒等于 $f(x)$。

核心概念

1.3 定积分的黎曼和（Riemann Sum）定义

$$\int_a^b f(x)\,dx = \lim_{\lambda \to 0} \sum_{i=1}^n f(\xi_i)\,\Delta x_i \quad \left(\lambda = \max_{1\le i\le n}\{\Delta x_i\}\right)$$

黎曼积分的经典四步法：

  1. 分割：在区间 $[a, b]$ 中插入分点 $a = x_0 < x_1 < \dots < x_n = b$，分成 $n$ 个小区段，记 $\Delta x_i = x_i - x_{i-1}$，取模长 $\lambda = \max\{\Delta x_i\}$。
  2. 近似：在每个小区间 $[x_{i-1}, x_i]$ 上任取一点 $\xi_i$，以矩形面积 $f(\xi_i)\Delta x_i$ 近似曲边小条面积。
  3. 求和：构建积分和式 $S_n = \sum_{i=1}^n f(\xi_i)\Delta x_i$。
  4. 取极限：令 $\lambda \to 0$，若极限与分割及 $\xi_i$ 选取无关且恒存在，此极限即为定积分 $\int_a^b f(x)dx$。

几何意义：当 $f(x) \ge 0$ 时，$\int_a^b f(x)dx$ 表示由曲线 $y=f(x)$、直线 $x=a$、$x=b$ 与 $x$ 轴所围成的曲边梯形的面积；一般情况下为 $x$ 轴上方与下方区域面积的代数和。

核心定理

1.4 微积分基本定理（牛顿 - 莱布尼茨公式）

$$\int_a^b f(x)\,dx = F(b) - F(a) = \Big[ F(x) \Big]_a^b \quad \left(\text{其中 } F'(x) = f(x)\right)$$

引理：变上限积分的求导定理

设 $f(x)$ 在 $[a, b]$ 上连续，定义变上限积分函数 $\Phi(x) = \int_a^x f(t)\,dt$（$x \in [a, b]$），则 $\Phi(x)$ 在 $[a, b]$ 上可导，且：$$\Phi'(x) = \frac{d}{dx}\left(\int_a^x f(t)\,dt\right) = f(x)$$

步骤 1：由导数定义计算 $\Phi'(x)$

给自变量 $x$ 一个增量 $\Delta x$，使得 $x + \Delta x \in [a, b]$，对应的函数增量为：

$$\Delta \Phi = \Phi(x+\Delta x) - \Phi(x) = \int_a^{x+\Delta x} f(t)\,dt - \int_a^x f(t)\,dt = \int_x^{x+\Delta x} f(t)\,dt$$

步骤 2：应用定积分第一中值定理

因为 $f(t)$ 在闭区间 $[x, x+\Delta x]$ 上连续，由积分第一中值定理，必存在介于 $x$ 与 $x + \Delta x$ 之间的点 $\xi$，使得：

$$\int_x^{x+\Delta x} f(t)\,dt = f(\xi)\,\Delta x \quad (\xi \text{ 介于 } x \text{ 与 } x+\Delta x \text{ 之间})$$

因此差商为：$\frac{\Delta \Phi}{\Delta x} = \frac{f(\xi)\Delta x}{\Delta x} = f(\xi)$。

步骤 3：取极限 $\Delta x \to 0$

当 $\Delta x \to 0$ 时，必有 $\xi \to x$。又因 $f(x)$ 在点 $x$ 处连续，故：

$$\Phi'(x) = \lim_{\Delta x \to 0} \frac{\Delta \Phi}{\Delta x} = \lim_{\Delta x \to 0} f(\xi) = \lim_{\xi \to x} f(\xi) = f(x)$$

这表明 $\Phi(x)$ 是 $f(x)$ 在区间 $[a, b]$ 上的一个原函数。

步骤 4：引入任意原函数 $F(x)$ 完成证明

设 $F(x)$ 是 $f(x)$ 的任意一个原函数，由于同一个函数的任意两个原函数只相差一个常数，故存在常数 $C$，使得：

$$\Phi(x) = F(x) + C$$

在等式两边令 $x = a$，由于 $\Phi(a) = \int_a^a f(t)\,dt = 0$，得：

$$0 = F(a) + C \implies C = -F(a)$$

因此，$\Phi(x) = F(x) - F(a)$。再令 $x = b$，即得：

$$\Phi(b) = \int_a^b f(t)\,dt = F(b) - F(a)$$

证毕。该定理将求定积分的极限求和问题，彻底转化为求被积函数的原函数运算，是整个微积分学的基石。

第二部分：求导法则与常用导数公式（附逐一推导）

2.1 求导四则运算、链式法则与反函数求导法则

求导法则

乘积法则与商的求导法则

$$(u \cdot v)' = u'v + u v' \qquad\text{及}\qquad \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2} \quad (v \neq 0)$$

1. 乘积法则 $(uv)' = u'v + uv'$ 推导：

设 $y = u(x)v(x)$，对自变量 $x$ 施加增量 $\Delta x$：

$$\Delta y = u(x+\Delta x)v(x+\Delta x) - u(x)v(x)$$

在分子中巧妙地“减一项再加一项” $u(x)v(x+\Delta x)$：

$$\Delta y = [u(x+\Delta x)v(x+\Delta x) - u(x)v(x+\Delta x)] + [u(x)v(x+\Delta x) - u(x)v(x)]$$ $$= [u(x+\Delta x) - u(x)]v(x+\Delta x) + u(x)[v(x+\Delta x) - v(x)] = \Delta u \cdot v(x+\Delta x) + u(x)\cdot \Delta v$$

两端同除以 $\Delta x$ 并取极限 $\Delta x \to 0$（由 $v(x)$ 可导必连续知 $\lim_{\Delta x\to 0} v(x+\Delta x) = v(x)$）：

$$(uv)' = \lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = \lim_{\Delta x \to 0} \left[ \frac{\Delta u}{\Delta x} v(x+\Delta x) + u(x) \frac{\Delta v}{\Delta x} \right] = u'(x)v(x) + u(x)v'(x)$$

2. 商法则 $(u/v)' = \frac{u'v - uv'}{v^2}$ 推导：

同理，设 $y = \frac{u(x)}{v(x)}$，计算差商：

$$\frac{\Delta y}{\Delta x} = \frac{\frac{u(x+\Delta x)}{v(x+\Delta x)} - \frac{u(x)}{v(x)}}{\Delta x} = \frac{u(x+\Delta x)v(x) - u(x)v(x+\Delta x)}{v(x+\Delta x)v(x)\Delta x}$$

分子同样加入中间项：$[u(x+\Delta x) - u(x)]v(x) - u(x)[v(x+\Delta x) - v(x)]$，则：

$$\lim_{\Delta x\to 0} \frac{\Delta y}{\Delta x} = \lim_{\Delta x\to 0}\frac{\frac{\Delta u}{\Delta x}v(x) - u(x)\frac{\Delta v}{\Delta x}}{v(x+\Delta x)v(x)} = \frac{u'(x)v(x) - u(x)v'(x)}{v(x)^2}$$
求导法则

复合函数链式法则与反函数求导法则

$$(f(g(x)))' = f'(g(x)) \cdot g'(x) \qquad\text{及}\qquad \frac{dy}{dx} = \frac{1}{\frac{dx}{dy}} \quad \left(\frac{dx}{dy} \neq 0\right)$$

1. 链式法则推导：

设 $y = f(u)$，$u = g(x)$。当 $x$ 获得增量 $\Delta x$ 时，中间变量 $u$ 获得增量 $\Delta u = g(x+\Delta x) - g(x)$，进而 $y$ 获得增量 $\Delta y = f(u+\Delta u) - f(u)$。

由 $f(u)$ 可导性，$\Delta y = f'(u)\Delta u + \alpha \Delta u$，其中当 $\Delta u \to 0$ 时无穷小量 $\alpha \to 0$。两边同除以 $\Delta x$：

$$\frac{\Delta y}{\Delta x} = f'(u)\frac{\Delta u}{\Delta x} + \alpha \frac{\Delta u}{\Delta x}$$

因为 $g(x)$ 可导必连续，当 $\Delta x \to 0$ 时必有 $\Delta u \to 0$，进而 $\alpha \to 0$。两边取极限即得：

$$\frac{dy}{dx} = \lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = f'(u) \lim_{\Delta x\to 0}\frac{\Delta u}{\Delta x} + 0 = f'(g(x)) \cdot g'(x)$$

2. 反函数求导法则推导：

设函数 $y = f(x)$ 在区间内单调可导，且 $f'(x) \neq 0$，则其存在单调反函数 $x = f^{-1}(y)$。对反函数的自变量 $y$ 给予增量 $\Delta y \neq 0$，由反函数严格单调性，对应 $\Delta x \neq 0$：

$$\frac{\Delta x}{\Delta y} = \frac{1}{\frac{\Delta y}{\Delta x}}$$

因反函数连续，当 $\Delta y \to 0$ 时 $\Delta x \to 0$。两边取极限：

$$\frac{dx}{dy} = \lim_{\Delta y \to 0} \frac{\Delta x}{\Delta y} = \frac{1}{\lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x}} = \frac{1}{f'(x)} \implies \frac{dy}{dx} = \frac{1}{\frac{dx}{dy}}$$

2.2 幂函数、指数函数与对数函数的导数及推导

导数公式 1

幂函数求导公式 $(x^n)' = n x^{n-1}$

$$\frac{d}{dx}\big(x^n\big) = n x^{n-1} \quad (n \in \mathbb{R})$$

证法 1（正整数 $n$ 时利用二项式定理）：

$$\lim_{\Delta x \to 0} \frac{(x+\Delta x)^n - x^n}{\Delta x} = \lim_{\Delta x \to 0} \frac{\left[x^n + n x^{n-1}\Delta x + \frac{n(n-1)}{2}x^{n-2}(\Delta x)^2 + \dots + (\Delta x)^n\right] - x^n}{\Delta x}$$ $$= \lim_{\Delta x \to 0} \left[ n x^{n-1} + \frac{n(n-1)}{2}x^{n-2}\Delta x + \dots + (\Delta x)^{n-1} \right] = n x^{n-1}$$

证法 2（推广到任意实数 $\alpha$）：利用对数求导法，设 $y = x^\alpha = e^{\alpha \ln x}$，由链式法则：

$$y' = e^{\alpha \ln x} \cdot (\alpha \ln x)' = x^\alpha \cdot \frac{\alpha}{x} = \alpha x^{\alpha - 1}$$
导数公式 2

指数函数求导公式 $(a^x)' = a^x \ln a$ 与 $(e^x)' = e^x$

$$\frac{d}{dx}\big(a^x\big) = a^x \ln a \quad (a > 0, a \neq 1) \qquad\text{特别地，}\qquad \frac{d}{dx}\big(e^x\big) = e^x$$

由导数的极限定义：

$$(a^x)' = \lim_{\Delta x \to 0} \frac{a^{x+\Delta x} - a^x}{\Delta x} = a^x \cdot \lim_{\Delta x \to 0} \frac{a^{\Delta x} - 1}{\Delta x}$$

令 $t = a^{\Delta x} - 1$，则 $a^{\Delta x} = 1 + t$，两边取对数得 $\Delta x \ln a = \ln(1 + t) \implies \Delta x = \frac{\ln(1+t)}{\ln a}$。当 $\Delta x \to 0$ 时 $t \to 0$：

$$\lim_{\Delta x \to 0} \frac{a^{\Delta x} - 1}{\Delta x} = \lim_{t \to 0} \frac{t}{\frac{\ln(1+t)}{\ln a}} = \ln a \cdot \lim_{t \to 0} \frac{1}{\ln(1+t)^{1/t}} = \ln a \cdot \frac{1}{\ln e} = \ln a$$

代回原式即得：$(a^x)' = a^x \ln a$。当 $a = e$ 时，$\ln e = 1$，故 $(e^x)' = e^x$。

导数公式 3

对数函数求导公式 $(\log_a x)' = \frac{1}{x\ln a}$ 与 $(\ln x)' = \frac{1}{x}$

$$\frac{d}{dx}\big(\log_a x\big) = \frac{1}{x \ln a} \qquad\text{特别地，}\qquad \frac{d}{dx}\big(\ln x\big) = \frac{1}{x}$$

对 $y = \ln x$，利用对数的运算性质 $\ln A - \ln B = \ln(A/B)$：

$$\frac{\Delta y}{\Delta x} = \frac{\ln(x+\Delta x) - \ln x}{\Delta x} = \frac{1}{\Delta x}\ln\left(1 + \frac{\Delta x}{x}\right) = \frac{1}{x} \cdot \frac{x}{\Delta x}\ln\left(1 + \frac{\Delta x}{x}\right) = \frac{1}{x}\ln\left[\left(1 + \frac{\Delta x}{x}\right)^{\frac{x}{\Delta x}}\right]$$

令 $t = \frac{\Delta x}{x}$，当 $\Delta x \to 0$ 时 $t \to 0$。根据重要极限 $\lim_{t\to 0}(1+t)^{1/t} = e$ 及对数函数连续性：

$$(\ln x)' = \lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = \frac{1}{x} \ln\left[ \lim_{t\to 0}(1+t)^{1/t} \right] = \frac{1}{x}\ln e = \frac{1}{x}$$

对于一般对数：$\log_a x = \frac{\ln x}{\ln a}$，由常数倍性质即得 $(\log_a x)' = \frac{1}{x\ln a}$。

2.3 三角函数导数公式及推导

导数公式 4

正弦与余弦函数求导公式

$$\frac{d}{dx}(\sin x) = \cos x \qquad\text{及}\qquad \frac{d}{dx}(\cos x) = -\sin x$$

1. 推导 $(\sin x)' = \cos x$：运用三角函数和差化积公式 $\sin\alpha - \sin\beta = 2\sin\frac{\alpha-\beta}{2}\cos\frac{\alpha+\beta}{2}$：

$$\Delta y = \sin(x+\Delta x) - \sin x = 2 \sin\frac{\Delta x}{2} \cos\left(x + \frac{\Delta x}{2}\right)$$ $$\lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = \lim_{\Delta x \to 0} \left[ \frac{\sin(\Delta x / 2)}{\Delta x / 2} \cdot \cos\left(x + \frac{\Delta x}{2}\right) \right] = 1 \cdot \cos x = \cos x$$

2. 推导 $(\cos x)' = -\sin x$：由诱导公式 $\cos x = \sin\left(\frac{\pi}{2} - x\right)$ 与复合函数链式法则：

$$(\cos x)' = \left[\sin\left(\frac{\pi}{2} - x\right)\right]' = \cos\left(\frac{\pi}{2} - x\right) \cdot \left(\frac{\pi}{2} - x\right)' = (\sin x) \cdot (-1) = -\sin x$$
导数公式 5

$\tan x, \cot x, \sec x, \csc x$ 的导数

$$(\tan x)' = \sec^2 x, \quad (\cot x)' = -\csc^2 x, \quad (\sec x)' = \sec x\tan x, \quad (\csc x)' = -\csc x\cot x$$

1. $(\tan x)'$ 推导： $\tan x = \frac{\sin x}{\cos x}$，由商法则：

$$(\tan x)' = \frac{(\sin x)'\cos x - \sin x(\cos x)'}{\cos^2 x} = \frac{\cos x \cdot \cos x - \sin x(-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{\cos^2 x} = \sec^2 x$$

2. $(\sec x)'$ 推导： $\sec x = \frac{1}{\cos x} = (\cos x)^{-1}$：

$$(\sec x)' = -(\cos x)^{-2} \cdot (\cos x)' = -\frac{1}{\cos^2 x} \cdot (-\sin x) = \frac{1}{\cos x} \cdot \frac{\sin x}{\cos x} = \sec x \tan x$$

同理可推得 $(\cot x)' = -\csc^2 x$ 与 $(\csc x)' = -\csc x\cot x$。

2.4 反三角函数导数公式及推导

导数公式 6

$(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$ 与 $(\arccos x)' = -\frac{1}{\sqrt{1-x^2}}$

$$\frac{d}{dx}(\arcsin x) = \frac{1}{\sqrt{1-x^2}} \qquad\text{及}\qquad \frac{d}{dx}(\arccos x) = -\frac{1}{\sqrt{1-x^2}} \quad (|x| < 1)$$

推导 $(\arcsin x)'$：设 $y = \arcsin x$（$x \in (-1, 1), y \in (-\frac{\pi}{2}, \frac{\pi}{2})$），则其反函数为 $x = \sin y$。由反函数求导法则：

$$\frac{dy}{dx} = \frac{1}{\frac{dx}{dy}} = \frac{1}{(\sin y)'} = \frac{1}{\cos y}$$

因为当 $y \in (-\frac{\pi}{2}, \frac{\pi}{2})$ 时，$\cos y > 0$，所以 $\cos y = \sqrt{1 - \sin^2 y} = \sqrt{1 - x^2}$，代回得：

$$(\arcsin x)' = \frac{1}{\sqrt{1 - x^2}}$$

推导 $(\arccos x)'$：因为 $\arcsin x + \arccos x = \frac{\pi}{2}$，两端直接对 $x$ 求导：

$$(\arccos x)' = \left(\frac{\pi}{2} - \arcsin x\right)' = 0 - \frac{1}{\sqrt{1 - x^2}} = -\frac{1}{\sqrt{1 - x^2}}$$
导数公式 7

$(\arctan x)' = \frac{1}{1+x^2}$ 与 $(\text{arccot}\,x)' = -\frac{1}{1+x^2}$

$$\frac{d}{dx}(\arctan x) = \frac{1}{1+x^2} \qquad\text{及}\qquad \frac{d}{dx}(\text{arccot}\,x) = -\frac{1}{1+x^2}$$

推导 $(\arctan x)'$：设 $y = \arctan x$（$x \in \mathbb{R}, y \in (-\frac{\pi}{2}, \frac{\pi}{2})$），反函数为 $x = \tan y$。根据反函数求导法则：

$$\frac{dy}{dx} = \frac{1}{\frac{dx}{dy}} = \frac{1}{(\tan y)'} = \frac{1}{\sec^2 y}$$

利用三角恒等式 $\sec^2 y = 1 + \tan^2 y$：

$$(\arctan x)' = \frac{1}{1 + \tan^2 y} = \frac{1}{1 + x^2}$$

同理，因 $\arctan x + \text{arccot}\,x = \frac{\pi}{2}$，求导即得 $(\text{arccot}\,x)' = -\frac{1}{1+x^2}$。

第三部分：积分法则与常用不定积分公式（附逐一推导）

3.1 积分运算法则：换元积分法与分部积分法

积分法则

第一与第二类换元积分法

$$\int f(\varphi(x))\varphi'(x)\,dx = \left[ \int f(u)\,du \right]_{u=\varphi(x)} \qquad\text{及}\qquad \int f(x)\,dx = \left[ \int f(\psi(t))\psi'(t)\,dt \right]_{t=\psi^{-1}(x)}$$

1. 第一类换元积分法（凑微分法）： 实质上是复合函数求导法则的逆运算。若 $F'(u) = f(u)$，由链式法则 $\frac{d}{dx}[F(\varphi(x))] = F'(\varphi(x))\varphi'(x) = f(\varphi(x))\varphi'(x)$。根据不定积分定义：$\int f(\varphi(x))\varphi'(x)dx = F(\varphi(x)) + C = \left.\int f(u)du\right|_{u=\varphi(x)}$。

2. 第二类换元积分法（变量置换法）： 当被积函数含有复杂式子（如 $\sqrt{a^2-x^2}$）难以直接凑微分时，令 $x = \psi(t)$（$\psi'(t) \neq 0$ 且存在反函数 $t = \psi^{-1}(x)$），则 $dx = \psi'(t)dt$，求出积分后再用反函数回代。

积分法则

分部积分法公式

$$\int u\,dv = uv - \int v\,du \quad \Longleftrightarrow \quad \int u(x)v'(x)\,dx = u(x)v(x) - \int v(x)u'(x)\,dx$$

由两个可导函数乘积的微分公式：

$$d(uv) = u\,dv + v\,du$$

移项整理得：

$$u\,dv = d(uv) - v\,du$$

两边同时取不定积分，由不定积分的线性性质：

$$\int u\,dv = \int d(uv) - \int v\,du = uv - \int v\,du$$

💡 选 $u$ 的常用口诀：“反对幂指三”（反三角、对数、幂函数、指数、三角），排在前面的优先选作 $u$。

3.2 常用不定积分公式及逐个推导过程（1 ~ 16）

公式 1 ~ 3

常数、幂函数与 $\frac{1}{x}$ 的积分

$$\int k\,dx = kx + C, \qquad \int x^\mu\,dx = \frac{x^{\mu+1}}{\mu+1} + C \quad (\mu \neq -1), \qquad \int \frac{1}{x}\,dx = \ln|x| + C$$

1. 幂函数推导：由求导公式 $\left(\frac{x^{\mu+1}}{\mu+1}\right)' = \frac{1}{\mu+1} \cdot (\mu+1)x^\mu = x^\mu$（当 $\mu \neq -1$），故其原函数即为 $\frac{x^{\mu+1}}{\mu+1} + C$。

2. $\int \frac{1}{x}dx = \ln|x| + C$ 推导：

  • 当 $x > 0$ 时，$|x| = x$，$(\ln x)' = \frac{1}{x}$；
  • 当 $x < 0$ 时，$|x| = -x$，利用复合函数求导：$[\ln(-x)]' = \frac{1}{-x} \cdot (-1) = \frac{1}{x}$。

综上，无论 $x > 0$ 还是 $x < 0$，均有 $(\ln|x|)' = \frac{1}{x}$，故积分结果统一表示为 $\ln|x| + C$。

公式 4 ~ 7

指数函数与基本三角函数的积分

$$\int a^x\,dx = \frac{a^x}{\ln a} + C, \quad \int e^x\,dx = e^x + C, \quad \int \cos x\,dx = \sin x + C, \quad \int \sin x\,dx = -\cos x + C$$ $$\int \sec^2 x\,dx = \tan x + C, \qquad \int \csc^2 x\,dx = -\cot x + C$$

上述公式全部直接对应导数基本公式的逆运算：

• 因 $\left(\frac{a^x}{\ln a}\right)' = \frac{a^x\ln a}{\ln a} = a^x \implies \int a^x dx = \frac{a^x}{\ln a} + C$。

• 因 $(-\cos x)' = -(-\sin x) = \sin x \implies \int \sin x dx = -\cos x + C$。

• 因 $(\tan x)' = \sec^2 x \implies \int \sec^2 x dx = \tan x + C$；$(-\cot x)' = \csc^2 x \implies \int \csc^2 x dx = -\cot x + C$。

公式 8 ~ 11

$\tan x, \cot x, \sec x, \csc x$ 的不定积分

$$\int \tan x\,dx = -\ln|\cos x| + C = \ln|\sec x| + C \qquad\qquad \int \cot x\,dx = \ln|\sin x| + C$$ $$\int \sec x\,dx = \ln|\sec x + \tan x| + C \qquad\qquad \int \csc x\,dx = \ln|\csc x - \cot x| + C$$

1. $\int \tan x\,dx$ 推导：

$$\int \tan x\,dx = \int \frac{\sin x}{\cos x}\,dx = -\int \frac{d(\cos x)}{\cos x} = -\ln|\cos x| + C = \ln|\cos x|^{-1} + C = \ln|\sec x| + C$$

2. $\int \sec x\,dx$ 经典分子分母同乘推导：

分子分母同时乘以 $(\sec x + \tan x)$：

$$\int \sec x\,dx = \int \frac{\sec x(\sec x + \tan x)}{\sec x + \tan x}\,dx = \int \frac{\sec^2 x + \sec x \tan x}{\sec x + \tan x}\,dx$$

观察分子：$d(\sec x + \tan x) = (\sec x \tan x + \sec^2 x)dx$，分子恰为分母的微分！

$$= \int \frac{d(\sec x + \tan x)}{\sec x + \tan x} = \ln|\sec x + \tan x| + C$$

3. $\int \csc x\,dx$ 推导：

分子分母同乘 $(\csc x - \cot x)$：

$$\int \csc x\,dx = \int \frac{\csc x(\csc x - \cot x)}{\csc x - \cot x}\,dx = \int \frac{\csc^2 x - \csc x \cot x}{\csc x - \cot x}\,dx$$

因 $d(\csc x - \cot x) = (-\csc x \cot x - (-\csc^2 x))dx = (\csc^2 x - \csc x \cot x)dx$：

$$= \int \frac{d(\csc x - \cot x)}{\csc x - \cot x} = \ln|\csc x - \cot x| + C$$
公式 12

$\int \frac{1}{x^2+a^2}\,dx = \frac{1}{a}\arctan\frac{x}{a} + C$

$$\int \frac{1}{x^2+a^2}\,dx = \frac{1}{a}\arctan\left(\frac{x}{a}\right) + C \quad (a > 0)$$

推导：提取常数 $a^2$ 凑微分（或使用三角代换 $x = a \tan\theta$）：

$$\int \frac{1}{x^2+a^2}\,dx = \frac{1}{a^2}\int \frac{1}{\left(\frac{x}{a}\right)^2 + 1}\,dx = \frac{1}{a}\int \frac{1}{\left(\frac{x}{a}\right)^2 + 1}\,d\left(\frac{x}{a}\right)$$

因为 $\int \frac{1}{u^2+1}du = \arctan u + C$，令 $u = \frac{x}{a}$，即得：

$$= \frac{1}{a}\arctan\left(\frac{x}{a}\right) + C$$
公式 13

$\int \frac{1}{\sqrt{a^2-x^2}}\,dx = \arcsin\frac{x}{a} + C$

$$\int \frac{1}{\sqrt{a^2-x^2}}\,dx = \arcsin\left(\frac{x}{a}\right) + C \quad (a > 0, |x| < a)$$

第二类换元法推导：设 $x = a\sin\theta$（$\theta \in (-\frac{\pi}{2}, \frac{\pi}{2})$），则 $dx = a\cos\theta\,d\theta$，$a^2 - x^2 = a^2\cos^2\theta$：

$$\int \frac{1}{\sqrt{a^2-x^2}}\,dx = \int \frac{a\cos\theta}{\sqrt{a^2\cos^2\theta}}\,d\theta = \int \frac{a\cos\theta}{a\cos\theta}\,d\theta = \int 1\,d\theta = \theta + C$$

回代 $\theta = \arcsin\left(\frac{x}{a}\right)$ 即得：$\arcsin\left(\frac{x}{a}\right) + C$。

公式 14

$\int \frac{1}{x^2-a^2}\,dx = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C$

$$\int \frac{1}{x^2-a^2}\,dx = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C \quad (a \neq 0)$$

部分分式拆解：利用恒等式 $\frac{1}{x^2-a^2} = \frac{1}{(x-a)(x+a)} = \frac{1}{2a}\left[\frac{1}{x-a} - \frac{1}{x+a}\right]$：

$$\int \frac{1}{x^2-a^2}\,dx = \frac{1}{2a} \int \left( \frac{1}{x-a} - \frac{1}{x+a} \right) dx = \frac{1}{2a} \left[ \ln|x-a| - \ln|x+a| \right] + C$$

由对数运算法则 $\ln A - \ln B = \ln(A/B)$，化简即得：

$$= \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C$$
公式 15

$\int \frac{1}{\sqrt{x^2\pm a^2}}\,dx = \ln\left|x + \sqrt{x^2\pm a^2}\right| + C$

$$\int \frac{1}{\sqrt{x^2 \pm a^2}}\,dx = \ln\left|x + \sqrt{x^2 \pm a^2}\right| + C \quad (a > 0)$$

欧拉代换法：令 $t = x + \sqrt{x^2 \pm a^2}$，两边求微分：

$$dt = \left( 1 + \frac{2x}{2\sqrt{x^2 \pm a^2}} \right) dx = \left( \frac{\sqrt{x^2 \pm a^2} + x}{\sqrt{x^2 \pm a^2}} \right) dx = \frac{t}{\sqrt{x^2 \pm a^2}}\,dx$$

两边除以 $t$：

$$\frac{dt}{t} = \frac{dx}{\sqrt{x^2 \pm a^2}}$$

原本复杂的无理式积分奇迹般化为简单的倒数积分：

$$\int \frac{1}{\sqrt{x^2 \pm a^2}}\,dx = \int \frac{1}{t}\,dt = \ln|t| + C = \ln\left|x + \sqrt{x^2 \pm a^2}\right| + C$$
公式 16

$\int \sqrt{a^2-x^2}\,dx = \frac{x}{2}\sqrt{a^2-x^2} + \frac{a^2}{2}\arcsin\frac{x}{a} + C$

$$\int \sqrt{a^2-x^2}\,dx = \frac{x}{2}\sqrt{a^2-x^2} + \frac{a^2}{2}\arcsin\left(\frac{x}{a}\right) + C \quad (a > 0)$$

分部积分法推导：设待求积分为 $I = \int \sqrt{a^2-x^2}\,dx$，令 $u = \sqrt{a^2-x^2}$，$dv = dx$，则 $v = x$，$du = \frac{-x}{\sqrt{a^2-x^2}}dx$：

$$I = x\sqrt{a^2-x^2} - \int x \cdot \frac{-x}{\sqrt{a^2-x^2}}\,dx = x\sqrt{a^2-x^2} + \int \frac{x^2}{\sqrt{a^2-x^2}}\,dx$$

对后项分子的 $x^2$ 进行“加上 $a^2$ 再减去 $a^2$”的拆项处理：

$$\int \frac{x^2}{\sqrt{a^2-x^2}}\,dx = \int \frac{-(a^2 - x^2) + a^2}{\sqrt{a^2-x^2}}\,dx = -\int \sqrt{a^2-x^2}\,dx + a^2\int \frac{1}{\sqrt{a^2-x^2}}\,dx$$

注意到出现了待求积分本身 $-I$ 以及公式 13 的已知积分：

$$I = x\sqrt{a^2-x^2} - I + a^2 \arcsin\left(\frac{x}{a}\right)$$

移项合并同类项 $2I$：

$$2I = x\sqrt{a^2-x^2} + a^2 \arcsin\left(\frac{x}{a}\right)$$

两边同除以 $2$ 并加上任意常数 $C$：

$$I = \frac{x}{2}\sqrt{a^2-x^2} + \frac{a^2}{2}\arcsin\left(\frac{x}{a}\right) + C$$
