数学脚手架前置：3分钟“微工具”唤醒

预习第四章“动能定理与功能原理”前，先打通三个高频数理卡点：变力做功的线积分、动能定理的标量本质，以及保守力与势能的系统观。

微工具 A · 功的线积分

变力做功：元功与点积

位移微元 dr 上力的微元功为 dW = F·dr；总功是沿路径的线积分（标量）。

W = ∫AB F·dr = ∫ (F·v) dt
常见卡壳点：

误把变力做功当成 F·s（恒力公式）。力随位置变化时必须积分；点积意味着只有沿位移方向的分力做功，垂直分量不做功。

微工具 B · 动能定理

合外力功 = 动能增量

对单个质点，所有力做功的代数和等于动能变化，与路径、过程无关：

W合 = ΔEk = ½m v2− ½m v02
常见卡壳点：

瞬时功率 P = dWdt = F·v 是点积，仅当力与速度同向才简写为 P = Fv；动能定理对曲线运动同样成立，不必先分解力。

微工具 C · 保守力与势能

保守力 → 势能（系统观）

重力、弹力、万有引力、静电力为保守力，做功与路径无关，可定义势能 Ep 使 W保 = −ΔEp。

重力：Ep = mgh
弹性：Ep = 12k x2
引力：Ep = −G M mr
常见卡壳点：

势能属于“物体 + 场源”系统，不是单个物体的属性；重力势能零点可任选，差值才有意义。一对内力的功与参考系无关。

环节 2 / 4 · 预计 4 分钟 预测-观察-解释

POE 图像盲测：先预测，再揭示

在揭晓解析前，凭直觉做出选择。重点关注“做功是否与路径有关”与“一对内力总功”这两个易错图像。

沙盒 ①：不同路径，重力做功一样吗？

两质量相同的滑块分别自同一高台 A 沿“直滑梯”和“螺旋盘旋滑梯”（无摩擦）滑到地面 B。两路径长度相差很大。重力对两滑块做的功相比如何？

重力是保守力，WG = mgh 仅由初末位置的高度差决定，与路径形状、长度均无关。无论直下还是盘旋，只要起点与终点高度相同，重力做功就相同。

沙盒 ②：滑动摩擦力，“总功”到底多少？

木块在粗糙水平地面上滑行距离 s 后停下。木块受地面滑动摩擦力 f 向左，地面受木块摩擦力向右但地面不动。这一对滑动摩擦力的总功是多少？

单个力的功看其受力物体的位移：木块位移 s 做负功 −fs，地面位移为 0 做功为 0，故总功 −fs = −f·s相对，即摩擦生热。注意“一对内力功”与参考系选择无关。

环节 4 / 4 · 预计 3 分钟 高频错误观念纠偏

点击“揭示正确认知”核对你的理解。若仍有疑问，可在课堂或 AI 学伴中追问。

迷思：功是矢量

常见错误认识：功有方向，可以像力一样合成与分解。

正确：功是标量（力与位移的点积 F·r）。它只有正负、没有方向；正功表示动力输入能量，负功表示阻力消耗能量。

迷思：动能定理 = 功能原理

常见错误认识：两者是一回事，随便用哪一个都行。

正确：动能定理 W合 = ΔEk 针对单个质点；功能原理 W非保 = ΔE 针对系统，引入了势能。对质点用动能定理，对含势能的系统才用功能原理。

迷思：势能属于单个物体

常见错误认识：“物体的重力势能”只属于该物体本身。

正确：势能是相互作用能，属于“物体 + 场源（如地球）”组成的系统。说“物体的势能”只是一种简略说法，脱离系统无从定义势能。
