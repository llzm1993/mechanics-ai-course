数学脚手架前置：角量线量 · 转动惯量 · 滚动条件

刚体不是「一个质点」，而是无数质元被刚性约束在一起。先用 3 分钟把三件工具唤醒：① 角量与线量 v = ωr；② 转动惯量 J = ∫ r2 dm 与平行轴定理；③ 平面平行运动的动能分解与纯滚动条件。

角量与线量：同一刚体上各点 ω 相同、v 不同

拖动滑块实时重绘

① 角量是「整个刚体」的，线量是「每个点」的

v = ωr,   at = βr,   an = ω2r

定轴转动时，刚体上所有质元的 ω、β 完全相同（刚性约束），但到转轴距离 r 不同，线速度、切向加速度、向心加速度都随 r 变化。这正是把「质点公式」推广到「刚体」的桥梁。

⚠️ 匀角加速转动可照搬匀变速公式；但变角加速度必须对 β(t) 积分，不能套 ω = ω0 + βt。

② 转动惯量由「质量分布」与「转轴」共同决定

J = ∑ miri2 = ∫ r2 dm,   J = JC + md2

r2 加权意味着质量离轴越远，贡献增长越快。转动惯量是「转动惯性的量度」，不依赖刚体是否正在转动；只要指定转轴就能求。
常见形状：细杆（过质心）J = mL2/12、圆盘 mR2/2、球 2mR2/5、圆环 mR2。

⚠️ 平行轴定理中的 JC 必须过质心；正交轴定理只适用于薄刚体（Jz = Jx + Jy）。

③ 平面平行运动 = 质心平动 + 绕质心转动

Ek = 12 mvC2 + 12 JCω2,   vC = ωR

取质心为基点可把运动拆成两套独立方程：质心运动定律 F = maC 与绕质心转动定律 MC = JCβ。
纯滚动条件 vC = ωR 把两者锁在一起，此时接触点瞬时速度为零。

初中常背「同一根轻绳张力处处相等」，但它需要 轻绳 + 滑轮质量可忽略（或匀速）。滑轮一旦有转动惯量 J，就必须有净力矩来产生角加速度 β。

m1g − T1 = m1a；T2 = m2a；(T1 − T2)r = Jβ = ½m0r2 · a/r。

从三条方程到「形状决定快慢」

mg sinθ − f = maC（质心运动）；fR = JCβ（绕质心转动）；aC = βR（纯滚动）。

令 JC = βmR2，联立消去 f 与 β 得 aC = g sinθ1 + β。

β 越小越快：实心球 0.4 > 圆盘 0.5 > 圆环 1.0。质量与半径被完全约掉——决定快慢的只有质量分布。

别混淆：纯滚动时静摩擦力不做功（接触点瞬时静止），因此机械能守恒 mgh = ½mvC2 + ½JCω2；但静摩擦力是产生转动加速度的必要条件，斜面太陡（θ 超过临界）就会打滑，习题 7-22 求的正是这个最大倾角。
