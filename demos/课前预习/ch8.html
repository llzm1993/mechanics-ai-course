数学脚手架前置：3 个振动“微工具”唤醒

预习第八章“机械振动”前，先打通三个高频数理卡点：简谐振动的定义与三要素（A/ω/φ）、两类典型系统的角频率 ω，以及微分方程、旋转矢量与能量守恒。

微工具 A · 简谐振动定义与三要素

振幅 / 角频率 / 相位

任何满足 x = A cos(ωt + φ) 的运动都是简谐振动（SHM）。只需 A, ω, φ 三个量即可完全描述一次振动。

运动学三要素：
x = A cos(ωt + φ)
振幅 A
最大位移大小
角频率 ω
ω = 2π/T = 2πf
周期 T / 频率 f
T = 1/f
相位 ωt+φ
决定瞬时状态
课前预习常见卡壳点：

把“相位 ωt+φ”和“初相 φ”混为一谈。φ 只是 t=0 时的相位（由初始条件定）；判断两个振动“谁超前谁”，要看相位差 Δφ，而非各自初相的大小。

微工具 B · 典型系统的 ω

ω 由系统本身的物理性质决定，与初始条件（振幅）无关。

弹簧振子：ω = √(k/m)，T = 2π√(m/k)
单摆（小角）：ω = √(g/l)，T = 2π√(l/g)
竖直弹簧振子：平衡位置仅下移 mg/k，ω 仍为 √(k/m)。
课前预习常见卡壳点：

以为“拉得越远、周期越长”。T 由系统决定、与振幅无关（等时性）；竖直放置只是把平衡位置平移，并不改变周期。

微工具 C · 微分方程、旋转矢量法与能量守恒

SHM 本质
运动微分方程
x + ω2x = 0

加速度与位移成正比且反向——“线性回复”是 SHM 的本质判据。

旋转矢量法
A·(cosθ, sinθ)

长度 A 的矢量以角速 ω 匀速旋转，其 x 投影即 x(t)；矢量转角就是相位，可快速判断超前/滞后。

机械能守恒
E = 12kA2 = 12mv2 + 12kx2

总机械能守恒，动能与势能在 0 与 E 之间互换，平均各占一半。

课前预习常见卡壳点：

把“无阻尼”默认套到所有振动上。一旦出现阻尼，振幅随时间衰减、能量持续耗散，就不再是严格 SHM；旋转矢量法也只在简谐（匀速旋转）时成立。

环节 2 / 4 · 预计 4 分钟 Predict → Observe → Explain

POE 图像盲测：先预测，再揭晓物理原因

先凭直觉选择你认为正确的结论，点击后查看解析。重点纠正常见的“振幅影响周期”“重力改变周期”等直觉误判。

POE 1 · 竖直悬挂 vs 水平放置的同一弹簧振子

同一根弹簧、同一物块，分别水平放置（无重力干扰）与竖直悬挂（重力让它平衡位置下移）。从各自平衡位置附近轻拉后释放，两者的振动周期一样吗？

竖直弹簧振子的回复力仍来自弹簧形变差，重力被平衡位置的静伸长 mg/k 抵消，等效 ω 仍为 √(k/m)，周期与水平放置完全相同——重力只平移平衡位置，不改变动力学。

POE 2 · 单摆摆角从 5° 增大到 30°

同一单摆，分别在很小摆角（≈5°，近似简谐）和较大摆角（≈30°）下从静止释放。大摆角时的周期，与小幅近似 T0 = 2π√(l/g) 相比如何？

只有小角近似 sinθ ≈ θ 时单摆才是简谐、周期才与振幅无关；大角度下恢复力矩非线性（sinθ ≠ θ），精确周期随振幅增大而变长。

3D 闪卡排雷：8 张核心概念 / 公式 / 图像

逐张点击翻转，正面是概念或问题，反面是解释与公式。覆盖定义、三要素、典型系统、旋转矢量与能量。

正面 · 概念
什么是简谐振动（SHM）？
反面 · 解释
物体受力（或加速度）与相对平衡位置的位移成正比且反向，运动学上满足 x = A cos(ωt + φ)。本质是线性回复运动。
正面 · 概念
振幅 A 表示什么？
反面 · 解释
振动的最大位移大小，由初始能量 / 初始条件决定，与周期无关。
正面 · 公式
角频率 ω、周期 T、频率 f 的关系？
反面 · 公式
ω = 2π/T = 2πf，T = 1/f；它们由系统本身决定（等时性），不随振幅变。
正面 · 概念
什么是相位与初相？
反面 · 解释
相位 ωt+φ 决定任意时刻的运动状态；初相 φ 是 t=0 时的相位，由初始条件定。比较振动用相位差 Δφ。
正面 · 公式
弹簧振子的 ω 与 T？
反面 · 公式
ω = √(k/m)，T = 2π√(m/k)；质量越大或弹簧越软（k 越小），周期越长。
正面 · 公式
单摆（小角）的 ω 与 T？
反面 · 公式
ω = √(g/l)，T = 2π√(l/g)；与摆球质量无关，仅由摆长与 g 决定（小角近似）。
正面 · 图像
旋转矢量法怎么用？
反面 · 解释
以原点为心、长 A 的矢量绕 O 以角速 ω 旋转，其 x 投影即 x(t)；矢量转角 = 相位，可快速判断超前 / 滞后与时间关系。
正面 · 能量
简谐振动的能量关系？
反面 · 公式
总机械能 E = 12kA2 守恒，E = 12mv2 + 12kx2；动能↔势能互换，平均各占一半。
环节 4 / 4 · 预计 3 分钟 AI 学伴随时答疑

迷思图 & AI 学伴：3 个高频错误观念

点击“揭示正确认知”核对你的理解。以下误判在振动章节出现频率极高，课前先排雷。

迷思：回复力一定是弹力

常见错误认识：简谐振动的回复力就是弹簧的弹力。

正确：回复力是按“效果”命名的力，只要方向与位移相反、大小成正比即可；它可以是重力分力（单摆）、静摩擦力、电场力等，未必是弹簧弹力。

迷思：周期与振幅有关

常见错误认识：振幅越大，振动周期越长。

正确：对线性回复系统（弹簧、小角单摆），周期由 ω 决定、与振幅无关（等时性）；只有非线性系统（大摆角单摆）周期才随振幅变化。

迷思：单摆总在做简谐振动

常见错误认识：单摆的运动天然就是简谐振动。

正确：只有小角近似 sinθ ≈ θ 时单摆才是简谐；大角度下 sinθ ≠ θ 为非线性振动，周期随振幅增大，不能套用 T = 2π√(l/g)。
