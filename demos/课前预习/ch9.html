数学脚手架前置：微分方程 · 旋转矢量 · 能量守恒

振动是「往复」，但物理上真正要抓的是回复力与位移的线性关系。3 分钟唤醒三件工具：① &ddot;x + ω2x = 0 与特征量；② 旋转矢量与相位；③ E = ½kA2 的动能势能互换。

简谐振动：一条由初始条件决定的正弦曲线

拖动滑块实时重绘

① 判据：回复力与位移成正比反向

x + ω2x = 0  ⇒  x = A cos(ωt + φ)

只要系统以平衡位置为原点能化成这个线性微分方程，就是简谐振动。ω 由系统本身决定（弹簧振子 √(k/m)、单摆 √(g/l)），而 A 与 φ 由初始条件（初位移、初速度）确定。

② 旋转矢量：把相位变成几何角

A 以 ω 匀速旋转  ⇒  x = A cos(ωt + φ)

三个对应关系（课件 9.1.3）：矢量长度 = 振幅 A、初始角位置 = 初相 φ、转动角速度 = 圆频率 ω；矢量在 x 轴投影就是位移。
最大好处：同频率振动的合成变成矢量求和，相位差直接读成两矢量夹角。

③ 能量：总机械能恒定，动能势能互补

E = 12kA2 = 12mv2 + 12kx2

在端点（x=±A）：速度为零，能量全是势能；在平衡位置（x=0）：势能为零，能量全是动能。
动能与势能都以 2ω 的频率变化（一个周期内互换两次），但总和恒定——这正是第五章功能原理在振动中的体现。

从稳态解到共振条件

受迫振动方程 &ddot;x + 2β˙x + ω02x = f0cosωt 的解由瞬态 + 稳态两部分组成；瞬态衰减后只剩与驱动力同频的稳态振动。

对稳态振幅求极大，得 ωr = √(ω02 − 2β2) < ω0——共振频率并不严格等于固有频率，只有阻尼很小时才近似相等。

阻尼越大，共振峰越矮、越宽、越往低频移；阻尼趋零时峰值趋于无穷（无阻尼理想化）。

别混淆：「共振有害」与「共振有用」是一体两面——1940 年塔科玛桥坍塌、唐朝铜磬不敲自鸣是需要规避的共振；鱼洗、共振仪、收音机调谐、摩天大楼风阻尼器则是利用或抑制它。阻尼振动另有欠阻尼 / 临界阻尼 / 过阻尼三态，仪表指针快速回零用临界阻尼。
