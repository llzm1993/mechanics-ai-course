高中代数常见误区：

“既然单位矢量 |er| = 1 永远不变，常数求导等于 0，那 derdt 不就等于 0 吗？”

大学物理矢量真相：

直角系 i, j 方向固定，导数确实为 0；但极坐标 er 随质点运动而转动！方向改变就会产生差矢量 Δer。

等腰三角形微元实时演算： Δθ = 0.525 rad (30.1°)
弦长 |Δer| = 2 sin(Δθ/2)
0.5190
弧长近似 Δθ = θΔt
0.5250
当 Δt → 0 时，|Δer| ≈ Δθ，且方向严格垂直于 er（指向 eθ）：
derdt = θ eθ
deθdt = −θ er
✨ 口诀：单位矢量求导，模长变为角速度 θ，方向沿转动方向逆时针转 90°！

工具 1：复合函数链式消元法 a = vdvdx

变力运动必杀技

当加速度不仅随时间变，而是已知随位置或速度变化（例如弹簧振子 a = −kx/m 或空气阻力 a = −kv2）时，题目里没有时间 t，怎么求速度与位置的关系？

🏫 高中物理（仅限 a 恒定）
v2 − v02 = 2ax

一旦加速度 a(x) 随位置改变，高中公式立刻失效！

🎓 大学微积分（任意变加速通用）
a = dvdt = dvdx · dxdt = v dvdx

移项得 v dv = a(x) dx，两侧直接定积分！

点按体验：用大学分离变量法 3 秒推导高中公式 步骤 1 / 3
a = dvdt = dvdx · dxdt = v dvdx
核心思想：分子分母同乘微位移 dx，把 dx/dt 认作速度 v，成功消去时间 dt！
